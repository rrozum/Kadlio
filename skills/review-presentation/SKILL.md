# Ревью презентации

Начните с `read_project`, аудитории, цели и временного бюджета. Для выбранных слайдов изучайте только их и нужный соседний контекст.

Проверяйте историю и визуал вместе: одна ясная мысль, контекст незнакомых терминов, короткий текст, речь о той же мысли. Отличайте предоставленные факты от учебных примеров; не выдумывайте доказательства ради связной истории.

`render_slide` для затронутых слайдов 1280×720 возвращает настоящий image, geometry и clipping warnings; HTML сам по себе не подтверждает визуал. Проверяйте overflow, awkward wraps, контраст, растянутые картинки, расстояния и формат, скрывающий editable blocks. После layout/theme/image edit снова render и сравнение. Изучайте notes/annotations вместе со слайдом.

Различайте browser, PDF, PPTX structure и PowerPoint rendering. Текст/простые фигуры остаются editable; screenshot deck не равноценная замена. Явно обозначайте отличия сложного CSS.

Запрос ревью сначала даёт конкретные замечания: slide/block, влияние на аудиторию/визуал и минимальное полезное исправление. Меняйте при запросе исправления, иначе сохраняйте презентацию. Полный export не нужен для одной формулировки.
