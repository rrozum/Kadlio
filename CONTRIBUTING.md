# Участие в разработке

Изменение должно быть достаточно небольшим, чтобы его можно было объяснить и проверить. Начинайте описание с конкретной проблемы и итогового поведения.

Перед работой прочитайте [архитектуру](docs/architecture.md), [границы модулей](docs/modules.md) и [AGENTS.md](AGENTS.md). Для крупной доработки сначала зафиксируйте её область и затронутые части; независимый рефакторинг отделяйте от нового поведения.

## Рабочий цикл

1. Установите Node.js 24, зависимости через `npm ci` и Chromium через `npx playwright install chromium`; либо поднимите [Docker Compose](docs/docker.md).
2. Работайте с временным каталогом данных и нейтральными слайдами. Не копируйте производственную SQLite, пользовательские презентации или авторизацию в фикстуры.
3. Держите правила данных в движке, I/O в репозиториях, транспорт в модулях. Addon использует общий механизм изменения, а не пишет JSON/HTML самостоятельно.
4. Запустите проверки по области изменения. Для хранения/API/протокола — `npm test`; для браузерных сценариев — нужные UI-тесты либо `npm run test:ui`.
5. Опишите результат, проведённые проверки и оставшиеся ограничения.

## Требования к коду и PR

- Документация и поясняющие комментарии — на русском. Комментарий объясняет причину, инвариант или границу доверия, а не повторяет очевидную строку.
- Избегайте нового фреймворка, контейнера DI и автоматического поиска plugins без конкретной необходимости. Сборка модулей явная.
- Сохраняйте ID, CAS, черновики, SSE, текущую семантику экспорта и отказ нативным разрешениям агента.
- Для изменения визуала приложите проверенный снимок; для данных — сценарий сохранения/перезагрузки и конфликта.
- Сохраняйте атрибуцию адаптированного кода. Не включайте приватные данные, токены, пароли, инфраструктурные inventory или секретные настройки.
- Отличайте mock-проверку провайдера от ответа реальной модели. Не запускайте разрушительные тесты на пользовательских проектах.

Вклад с помощью ИИ принимается на общих условиях: автор отвечает за понимание решения, его необходимость и проверку. Вклад распространяется под [MIT](LICENSE).
