# Темы, живое редактирование и эффекты

**Темы** в верхнем меню открывает библиотеку. Встроенные темы доступны для чтения: создайте копию или тему из презентации. Отдельный редактор разблокирует общий template layer. Текст, линию, изображение или decoration можно выбрать, передвинуть, растянуть и настроить. Inspector обновляет холст сразу. Сохранение проверяет версию; конфликт сохраняет локальный исходник.

Панель исходника редактирует буквальные HTML/CSS. Переменные `{{author}}`, `{{brand}}`, `{{projectTitle}}`, `{{slideTitle}}`, `{{section}}`, `{{slideNumber}}`, `{{slideCount}}` остаются в template; значения preview не подменяют исходник. Переменные допустимы в тексте, а не URL/CSS-атрибутах. Script markup, handlers, imports и внешние ресурсы отклоняются/удаляются при сохранении. Собственный MP4/WebM может быть template video или `design.background` с `type:'video'`; JS презентации относится к отдельному runtime, не script tags темы.

HTML/CSS открывается с локальными Prettier и Prism. Открытие, отмена и применение неизменённого форматированного текста сохраняют исходные байты. Реальная правка обновляет preview, сохранение темы остаётся отдельным действием. При ошибке синтаксиса исходник остаётся редактируемым с индикатором ошибки. Тот же компонент используется для HTML слайда.

**← Темы** или **← К темам** из source dialog позволяют выйти. Несохранённые правки/черновик показывают **Продолжить редактирование** и **Выйти без сохранения**. Отмена/Escape сохраняют draft; подтверждение уходит без записи и повторного browser warning. Hard refresh и закрытие вкладки используют стандартное предупреждение браузера.

При создании презентации выбирается тема. Боковая панель умеет preview/apply библиотечной темы и возврат к исходному оформлению. Применение копирует design и ресурсы в презентацию; поздние правки библиотеки влияют только на будущие применения. Public/export используют самостоятельный snapshot. Обычный холст сохраняет template layer защищённым и не включает его в slide.body.

Импорт сохраняет исходный CSS. **Редактировать копию темы** переносит фон, header/footer и assets. Явная визуальная правка фона добавляет scoped overrides; открытие редактора само не меняет импорт.

## Живая обратная связь

Свойства холста и theme preview обновляются сразу. Автосохранение показывает saving/error. Сохранённые изменения агента/другого окна приходят через authenticated SSE и объединяются с сохранением выбранного слайда, chat draft, локальных HTML/notes, inline edit, annotation draft и текущего transform. Отложенное обновление повторяется после завершения локальной правки; конфликт версии всё ещё требует слияния.

## Переходы

Переходы — отдельные карточки между слайдами в filmstrip. **+** в промежутке или **Эффекты** показывает dissolve, rise, zoom, horizontal slide, blur и stagger. Три скорости позволяют настроить темп. Перетаскивание в занятый gap меняет переходы местами; копирование создаёт новый переход в пустом gap. Удаление сохраняет оба слайда. Reduced motion учитывается; runtime nodes/styles не становятся HTML.

Канонический `presentation.json.timeline` содержит slide references и `{type:'transition',id,preset,duration}`. Custom transition дополнительно хранит независимый `snippet:{snippetId,code,options}`. Timeline начинается/заканчивается слайдом, каждый слайд встречается один раз, в gap не больше одного перехода. Стандартная длительность 300–1400 мс. Перестановка сохраняет переходы в порядковых gap slots. Копия слайда получает самостоятельные HTML, notes/comments после оригинала перед исходящим переходом. Удаление внутреннего слайда удаляет исходящий и сохраняет входящий переход в объединённом gap; удаление крайнего удаляет соседний переход.

Старые `slide.effects` читаются без миграции при загрузке как входящие переходы. Эффект первого слайда используется в первом gap только без эффекта второго. У одного слайда gap нет. Сохранение timeline удаляет legacy fields; HTTP legacy effects переводит в boundary. MCP использует `update_timeline` с версией проекта и `duplicate_slide`; slide-edit tool не предлагает effects.

- Website и автономный HTML используют одну границу в обоих направлениях. Перескок через несколько слайдов не создаёт переход.
- PDF/PPTX показывают сохранённый static HTML без custom JS. `render_slide` может проверять runtime frame через `atMs`, default 800 мс.
- PPTX сохраняет поддерживаемые native text/shapes. Переход относится к входящему слайду; у первого нет предшествующей границы. Fade/push/zoom поддерживаются, blur/stagger приближаются fade; custom JS не имеет mapping. SVG может растеризоваться. XML-check не подтверждает вид в PowerPoint.

Element effects отдельно от переходов применяются к одному unlocked HTML/SVG, включая off-canvas. Code/options являются snapshot, каталог не переписывает deck, editor остаётся статичным. [Видео и JS](presentation-runtime.md).

Native mappings следуют [Open XML transition schema](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.presentation.transition?view=openxml-3.0.1). [reveal.js](https://revealjs.com/transitions/) изучался как референс выбора эффектов; его runtime не включён.
