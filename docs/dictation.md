# Диктовка и вывод агента

Кнопка микрофона в поле чата распознаёт русскую речь. Нажмите ещё раз, чтобы остановить запись. Результат появится в поле сообщения: его можно поправить и отправить обычной кнопкой. Диктовка сама не отправляет запрос агенту.

В браузерах с работающим Web Speech используется распознавание браузера. Доступ к микрофону запрашивается только после нажатия кнопки. Если сервис браузера недоступен, запись отправляется авторизованному серверу для распознавания. Поддерживается до 60 секунд; результат остаётся обычным текстом и работает с любым провайдером чата, включая ACP.

## Распознавание без API-ключа

На сервере установите [whisper.cpp](https://github.com/ggml-org/whisper.cpp) и многоязычную модель GGML. Модели `.en` предназначены только для английского. Код приложения не содержит бинарника или модели. Оператор задаёт абсолютные пути:

```dotenv
WHISPER_COMMAND=/opt/whisper/build/bin/whisper-cli
WHISPER_MODEL=/opt/whisper/models/ggml-base-q5_1.bin
```

Используется CPU CLI с двумя потоками. Одновременно выполняется одна задача; процесс ограничен таймаутом 90 секунд. На небольшом сервере начните с квантованной `base` или `tiny` и проверьте качество и время на своей речи. Запись переводится браузером в моно PCM WAV, 16 кГц, 16 бит. Сервер проверяет формат и длительность перед запуском. Временный файл и результат удаляются после завершения, ошибки или отмены; постоянного аудиоархива нет. Качество зависит от микрофона, произношения и выбранной модели.

`GET /api/transcription/status` сообщает доступность резервного распознавания. `POST /api/transcription` принимает `{data,mime:'audio/wav',language:'ru'}` с WAV в base64 и возвращает `{text}`. Оба маршрута требуют входа; ключи модели чата не используются. Браузер без поддержки захвата аудио покажет понятную ошибку.

## Чат

Во время запроса виден счётчик «Работает N секунд/минут». После завершения показывается итоговый ответ. Инструменты, промежуточные сообщения и статусы собраны в закрытый блок «Ход работы». Повторные обновления одного инструмента меняют его строку вместо создания новых карточек. Эти действия и время сохраняются в истории.

ACP различает видимые промежуточные сообщения и последний ответ по сообщениям и вызовам инструментов. Скрытые рассуждения модели в интерфейс не передаются. Для OpenAI-совместимого API промежуточный ответ с вызовами инструментов также относится к ходу работы. Разрешение на неизвестное действие агента показывается отдельно, если оно требуется для продолжения.

Тесты с имитацией микрофона проверяют вставку текста, отказ в доступе, остановку и резервный маршрут. Такая проверка не подтверждает качество реального микрофона; реальное распознавание проверяется отдельно с WAV-записью.
