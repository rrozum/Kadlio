# Редактируемый экспорт PPTX

Экспорт использует статическую верстку Chromium на холсте 1280 × 720. Пользовательский JavaScript не запускается. Порядок слайдов, метаданные, заметки и поддерживаемые переходы берутся из текущего проекта; экспорт не изменяет сохраненные данные.

## Что сохраняется

- Обычный HTML-текст остается редактируемым. Браузер определяет переносы и координаты каждого оформленного фрагмента. Цветные части строки, отступы в `pre`, пробелы и межбуквенные интервалы не склеиваются заново. Строка может состоять из нескольких объектов PowerPoint.
- Карточки, границы и линии остаются фигурами. Фиксированный большой `border-radius` создает скругленную плашку, процентный радиус 50% — эллипс. Круг сохраняется кругом.
- Цвет, прозрачность и обычный `linear-gradient` с RGB/RGBA-цветами и процентными позициями переносятся в собственные заливки PowerPoint. Поддерживается несколько цветовых остановок и фоновый цвет под полупрозрачным градиентом.
- Подчеркивание, зачеркивание и надчеркивание становятся отдельными редактируемыми линиями с цветом и толщиной из CSS. Учитывается оформление на родительском элементе.
- Текстовые `::before` и `::after` с вычисленным строковым содержимым становятся редактируемым текстом. Они исключаются из фонового снимка, чтобы надписи не дублировались.
- Фотографии, QR, видео-постеры, SVG и сложный декор остаются изображениями. Фон снимается без обычного содержимого, а отдельные изображения — без перекрывающих соседей. HTML-таблицы сохраняются как текст, ячейки и линии, а не как объект «Таблица PowerPoint».
- Заметки содержат отдельный абзац на каждый исходный перенос строки, включая пустые строки и отступы. Заметки не попадают на видимые слайды.

## Шрифты

Chromium через CDP сообщает фактический шрифт текста, включая системную замену отсутствующего шрифта из CSS. Вложенный `code` не меняет шрифт соседнего текста контейнера. Экспорт указывает фактическое семейство, размер, жирность и курсив.

В Linux `fontconfig` находит системный файл соответствующего начертания. Поддерживаемые TrueType/OpenType-файлы упаковываются целиком в EOT и встраиваются в PPTX через связи PresentationML. Встраивание не зависит от установленного PowerPoint. Учитываются разрешения `OS/2.fsType`: запрещенные для редактируемого встраивания и bitmap-only шрифты не включаются. Размер ограничен 8 МиБ на исходный файл и 32 МиБ встроенных данных на презентацию; число запросов шрифтов ограничено 64. Подмножества символов не создаются, поэтому можно дописывать текст тем же шрифтом.

Если `fontconfig` недоступен, файл не найден, формат не поддерживается или встраивание запрещено, экспорт сохраняет имя фактического семейства. Получателю тогда нужен этот шрифт. WOFF/WOFF2 webfonts и коллекции TTC не конвертируются и не встраиваются. Шрифт для отдельных символов внутри смешанного Unicode-фрагмента может отличаться: основной шрифт выбирается по числу глифов.

Формат встроенных шрифтов описан в [EOT](https://www.w3.org/submissions/EOT/) и [Microsoft Font Part](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/1663dabc-5d98-463f-889e-bcd9b77c3d34).

## Проверки и границы

Постобработка сохраняет пробелы и абзацы, исправляет объявления отсутствующих master-частей PptxGenJS и добавляет шрифты и градиенты. HTTP/API и проверка доступа остаются общими для всех форматов.

Регрессионные проверки: `node --test test/pptx-fidelity.test.js test/pptx-geometry.test.js test/timeline.test.js`. Проверка скачивания через UI: `node test/presentation-design-ui.js`.

XML-проверка не доказывает визуальное совпадение. При изменении экспортера нужно открыть контрольный PPTX в PowerPoint, проверить все затронутые слайды и заметки, особенно сочетания шрифтов, inline-текст, плашки и формулы. Сохранение, повторное открытие и изменение текста проверяются на отдельной копии.

PowerPoint и браузер по-разному сглаживают и размещают шрифты. Произвольные CSS transforms, stacking/clipping, тени, сложные фоновые изображения, радиальные/повторяющиеся градиенты, CSS counters и нестандартные виды текстовых линий не имеют полного соответствия в native PPTX. Экспорт не обещает пиксельное совпадение для любого HTML/CSS. PDF сохраняет браузерную верстку, автономный HTML — интерактивный показ.
