# Проверка архитектурного рефакторинга 0.8.0

Проверено 9 октября 2026 года. Область работы — перенос и разделение существующей логики, комментарии, документация и контейнерная поставка. Новые сценарии редактора, миграции данных и исправления прежних ошибок не входили в задачу.

## Сравнение до и после

Исходное состояние: `e6fed5b` / `studio-v0.7.3`. Рефакторинг исходников: `317b89a`.

| Проверка | До рефакторинга | После рефакторинга |
| --- | --- | --- |
| `npm test` | 144 пройдено | 157 пройдено, ошибок и пропусков нет |
| `npm run test:ui` | Все 33 команды прошли | Все 33 команды прошли |
| Форматы хранения | JSON/HTML/CSS и SQLite | Те же форматы, без миграции |
| Интерфейс | Существующие страницы и стили | Перенесены с сохранением компоновки |

Добавленные тесты проверяют настоящие границы рефакторинга: зависимости слоёв, контракты реестров, сохранение локальных черновиков, автономный JS-плеер после форматирования и совместимые команды запуска. Прежние API и браузерные сценарии сохранены.

## Что проверяют наборы

- Хранение, версии, конфликты, копирование, заметки, аннотации и очередь изменений.
- Вход и сессии, Host/Origin, приватность публичного просмотра, гостевые отзывы и решение владельца о передаче агенту.
- HTTP/SSE и mock-обмен OpenAI/ACP, инструменты MCP, ограничения контекста и отмена запросов.
- Холст, drag/drop, слои, замки, масштаб, исходник, темы, переменные, тур создания, материалы, каталоги и эффекты.
- Импорт PPTX и документов, реальные изображения предпросмотра, PDF/PPTX/автономный HTML, видео и sandbox JS.
- Существующие проверки производительности: нет перезагрузки iframe на вводе/листании и клонирования слайдов просмотрщиком.

Проверка графа импортов не обнаружила циклов или отсутствующих относительных файлов. Backend не импортирует frontend, движок не зависит от HTTP/ИИ/addons, shared не зависит от backend/frontend. Этот контракт проверяется обычным `npm test`.

Форматирование исходников проверено `npm run format:check`. HTML-страницы не форматировались автоматически: их whitespace может влиять на визуал. Отдельно сравнены существующие CSS и генераторы HTML; vendor-код, шрифты и юридические блоки сохранены.

## Docker и реальный браузер

Поднят отдельный Compose project с собственным volume и нейтральным тестовым аккаунтом. Пройдены вход, ручной тур, добавление текста/иконки/элемента, речь, аннотация с HTTP/SSE mock-провайдером, сохранение и перезагрузка, перестановка мышью, настройки публичной ссылки и экспорт трёх форматов. Также проверены копия темы, HTML/CSS, сохранение и повторное открытие. JS-ошибок браузера не обнаружено.

Дополнительная проверка кнопок в браузере покрыла смену темы приложения, масштаб, сохранение речи после reload, отмену исходника без изменения сохранённых байтов, листание и боковые панели. Проверены скриншоты редактора и темы; интерфейс редактора помещается в окно 1600 × 900 без прокрутки страницы.

Проверочный PDF содержит два слайда, PPTX — два слайда и редактируемый текст. Реальный нейтральный PPTX обработан LibreOffice внутри bubblewrap: предпросмотр получил PNG 1200 × 675. Контейнер работал под non-root, с readonly root filesystem, без capabilities и без незащищённого fallback конвертера.

Полная первоначальная Docker-сборка прошла. Повторная загрузка базового образа упёрлась в таймаут Docker Hub; финальные исходники собраны поверх ранее проверенного слоя тех же зависимостей и повторно проверены в Compose. Настройки поставки из-за таймаута не менялись.

## Границы результата

`npm audit --omit=dev` сообщил ноль известных уязвимостей производственных npm-зависимостей на дату проверки. Это результат npm-аудита, а не проверка всех внешних бинарников или гарантия отсутствия ошибок.

Проверки ИИ используют тестовые провайдеры: авторизация реального аккаунта Codex и живой ответ модели в эту проверку не входили. PowerPoint как настольная программа отдельно не запускался; существующие ограничения импорта/экспорта остаются описаны в README и руководствах.

Продакшен и личные презентации не использовались для записи тестовых изменений. Публикация на действующий сервер и в GitHub в рамках этого рефакторинга не выполнялась.
