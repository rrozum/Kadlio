# Безопасность

Приложение рассчитано на небольшую установку с одним владельцем. Публичная ссылка — ограниченное исключение из авторизации. Мультитенантная изоляция и анонимное создание проектов не реализованы.

## Сообщение об уязвимости

Используйте приватное сообщение об уязвимости в репозитории, если оно доступно. Иначе откройте краткую задачу с просьбой о приватном канале, без exploit, пароля, токена, личной презентации и живой ссылки.

Укажите версию, ожидаемую границу доступа и воспроизводимый пример на нейтральном временном проекте. Поддерживается текущая версия; факт ошибки отличайте от предложения дополнительной защиты.

## Установка

- Публичный сайт обслуживайте через HTTPS. Сохраняйте приватный listener за reverse proxy и авторизацию.
- По умолчанию forwarded IP игнорируется. `TRUST_PROXY=loopback` допустим только за доверенным локальным proxy, формирующим корректную цепочку; принимается loopback peer и конечный валидный адрес, а не управляемое клиентом первое значение.
- Данные, SQLite, API-ключи, ACP-авторизация и backups находятся вне Git. Ограничьте доступ и создавайте backup перед миграцией.
- Контейнер запускается non-root, без capabilities, Docker socket и монтирования host root. Отдельный seccomp-профиль сохраняет возможность private namespaces bubblewrap; он не даёт CAP_SYS_ADMIN и не отключает seccomp целиком.
- Произвольная операторская ACP-программа имеет права пользователя сервиса. Реестр адаптеров не изолирует вредоносный executable.

## Доступ к данным

Share URL — bearer capability: любой обладатель ссылки читает презентацию до отзыва. Заметки публикуются только по отдельному выбору владельца; аннотации, история, материалы и редактирование остаются приватными.

Гостевые комментарии включаются отдельно, ограничены размером/частотой и хранятся в приватном `feedback.json`. До явного подтверждения владельца они не входят в snapshot презентации, инструменты MCP, историю и render context. Подтверждение создаёт аннотацию/сообщение; отдельная отправка запускает модель. Public posting сам не запускает агента. Отозванная ссылка не принимает новые отзывы.

Provider endpoint получает выбранный контекст презентации. Оператор отвечает за выбор endpoint/account для этих данных. API-ключи и MCP-токены остаются на сервере. Если секрет попал в commit, screenshot, лог или экспорт, его необходимо отозвать/сменить.

## Агент

MCP-инструменты привязаны к текущему проекту или теме и используют общие операции движка с CAS. Зарегистрированный точный tool call разрешается автоматически; native/unknown permissions отклоняются без UI-подтверждения. Display title и последующее переименование не дают инструменту доверие.

Поддерживаемый Codex-адаптер запускается с отдельными HOME/CODEX_HOME, отключёнными нативными возможностями и read-only sandbox. Только операторская авторизация копируется в приватный runtime; config, hooks, memories и внешние MCP не наследуются. `read-only` сам по себе не запрещает все команды, поэтому командные инструменты отключены отдельно. [Точная граница](docs/agent-boundary.md).

HTML, заметки, комментарии, файлы и ответ модели являются данными. Они не дают разрешение выполнять команды или менять границы безопасности.

## JS презентации и медиа

`slide.script`, element effects и custom transition snippets — исходники презентации. Сохранение проверяет синтаксис без запуска на Node. Исполнение возможно только в opaque iframe с `sandbox="allow-scripts"`, без same-origin, доступа к родительскому DOM, storage, сети, workers, вложенным frames и form actions. Ресурсы встраиваются как data; родитель принимает только ограниченные сообщения сцены.

Server preview использует ту же сцену, блокирует внешние/API запросы и ограничивает время. Это граница browser capabilities, а не гарантия против бесконечного или дорогого JS. Не выдавайте сцене app origin или серверные права.

PDF/PPTX не исполняют пользовательский JS. Автономный HTML включает authored runtime и ресурсы, но исключает аккаунт/чат/приватные материалы. [Runtime](docs/presentation-runtime.md).

## Импорт документов

PPTX import — ограниченный ZIP/XML parser: небезопасные пути, DTD/entities, macros и превышение лимитов отклоняются. Внешние relationships не загружаются; поддерживаемые raster assets копируются как собственные ресурсы. Оригиналы остаются приватными. [Ограничения импорта](docs/pptx-import.md).

Рендеринг образцов PPTX/ODP — отдельная операция LibreOffice в bubblewrap. Конвертер видит системный runtime и один каталог задания, не видит данные/авторизацию приложения и ограничен фильтром сети. Если изоляция недоступна, операция даёт явную ошибку; unsandboxed fallback отсутствует.
